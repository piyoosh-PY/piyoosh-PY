### Featured project

**[CMIP: Clinical Member Intelligence Platform](https://github.com/piyoosh-PY/cmip)**
A member-360 platform on synthetic healthcare data. It has a dbt medallion pipeline on Postgres + pgvector, hybrid retrieval (Qdrant + BM25 + SQL), a LangGraph agent served over MCP and FastAPI, MLflow evals and a Next.js UI, all running in Docker Compose. It is now growing an integration sandbox with a HAPI FHIR server and Open Integration Engine (the open-source Mirth fork).
